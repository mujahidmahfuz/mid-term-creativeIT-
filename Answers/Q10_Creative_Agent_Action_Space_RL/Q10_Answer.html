Q10. Intelligent vs Creative Agent and Search, and Expanding the Action Space with RL

Question. Explain intelligent agent and creative agent, intelligent search and creative search. If a creative agent must expand its search space and action space, how can we write a function for it? Take product design with a utility-based agent and reinforcement learning to expand the action space. Explain different options.

1. The idea in plain words

An intelligent agent is very good at reaching a goal with the moves it already has. A creative agent also asks: "Do I have the right moves at all?" If the answer is no, it invents new moves. In product design this means the agent does not only pick features one by one. It notices which feature pairs work well together and turns each pair into a single new action. The agent's action space grows, so the space of designs it can reach grows too.

4. Assumptions

  • A phone has 6 slots (screen, battery, camera, body, sensors, AI) with 4 options each.
  • Basic action = fix one slot to one option, giving 6 × 4 = 24 actions. The agent has only 3 steps per design.
  • Utility = sum of feature quality + hidden synergy bonuses for 3 feature pairs (for example the right body with the right screen). The agent does not know the pairs. It must discover them.
  • The agent is a utility-based learner using epsilon-greedy Q-learning. It runs 1,500 design episodes and expands its actions at episode 500.

5. A function that expands the search and action space

The idea: look at the best designs built so far and find action pairs that keep appearing. Each pair becomes a new macro-action that sets two slots in one step. With 3 steps, the agent can now fill up to 6 slots, so designs that were unreachable become reachable.

function expand(actions A, best_runs R):
    pairs ← count every consecutive pair (ai, ai+1) in the top runs R
    for each pair (a, b) among the top-k most frequent:
        if (a, b) not in A:  A.add( macro(a, b) )          # new action = a then b in one step
    return A                                                  # bigger action space, bigger search space

function CreativeRL(A, episodes, warmup):
    for ep = 1 to episodes:
        if ep = warmup + 1: A ← expand(A, top 60 runs);  reset Q
        design ← run epsilon-greedy episode using actions in A
        reward ← utility(design)
        update Q(state, action) toward reward
    return Q, A

6. Step-by-step approach

  1. Start with 24 basic actions and the utility function (the agent's "happiness" measure).
  2. Run design episodes. Each has 3 steps. The agent picks mostly the best-known action and sometimes a random one.
  3. Score the finished phone with the utility function and update the Q-values with that reward.
  4. After the warm-up (episode 500), look at the 60 best runs and mine the most frequent action pairs.
  5. Add them as macro-actions. Clear the old Q-values, because the action list has changed.
  6. Keep learning with the bigger action set. Compare with an agent whose actions never grow.

10. Summary

An intelligent agent searches well inside the space it is given. A creative agent also changes the space: it creates new actions and redefines neighbours. By mining its best action pairs into macro-actions, the RL agent grew its action set from 24 to 28 and nearly doubled its final utility (3.11 to 6.46) in the same three steps. Other options are parameterised actions, analogy, human co-creators, curiosity and genetic search over action sequences.
