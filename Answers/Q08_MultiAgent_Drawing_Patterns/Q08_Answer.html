Q8. Search Space and a Multi-Agent System that Combines Two Drawing Patterns

Question. What is a search space? Design a multi-agent system that combines two drawing patterns into a new creative drawing, by expanding the search space or adding a new action. How can we combine two actions? Both agents introduce new combinations to create new states. What could the fitness function be?

1. The idea in plain words

Think of two artists. One only draws square spirals; the other only draws stars. Each artist knows a few moves: go forward, turn, make the next step longer. Neither can draw anything new with their own moves alone. The trick is to glue one move from each artist into a brand-new move, for example "turn like the star and grow like the spiral" in a single step. That new move opens up drawings neither artist could reach before. Two agents keep proposing such combinations, a fitness function scores them, and a shared archive remembers what is already done.

2. What is a search space?

The search space is the set of all states an agent can reach from the start state by applying its actions (operators), again and again. It is an implicit graph: states are nodes and actions are edges. We never build it fully; the search algorithm explores a small part of it. Two things decide its size:

  • The action set. More actions means more edges out of every state.
  • The depth. With a actions and sequences of length L, there are aL possible sequences.

Here a state is a drawing program (a motif of actions repeated n times). Adding new actions therefore expands the search space directly. That is the creative lever in this question.

3. Assumptions

  • Drawings are made by a "turtle" pen. The basic actions are F (forward), L(θ) (turn left), G(g) (make the step longer) and C (change colour).
  • Agent A owns the square spiral: repeat [F, L(90°), G(3)] 40 times.
  • Agent B owns the five-point star: repeat [F, L(144°)] 5 times.
  • The agents work in rounds (6 rounds, 5 proposals each per round) and share one archive of "already seen" drawings.

5. How can we combine two actions?

WayWhat it meansExample from our run
ComposeRun one action right after the other and treat the pair as one new action: a₂∘a₁ LG = L(144°) from the star + G(3) from the spiral. The result is a growing star-spiral.
BlendMix the parameters of two similar actions BLEND turn = α·90° + (1−α)·144°. With α = 0.5 that is 117°.
NestPack one whole pattern into a single action and use it inside the other STAR is drawn at every corner of the spiral (two levels of scale).
InterleaveAlternate the two parents' moves One spiral move, then one star move, and so on.

Every way creates a new action. The action space grows from 4 to 7. For a motif of 6 actions the search space grows from 46 = 4,096 to 76 = 117,649 programs: 28.7 times larger (Figure 3, right). This is exactly how adding an action expands the search space.

6. Step-by-step approach

  1. Give each agent its parent pattern and the four basic actions.
  2. In each round, every agent picks one action from each parent and combines them (compose, blend, nest or interleave).
  3. Repeat the new action n times to get a drawing, which is a new state.
  4. Score it with the fitness function.
  5. If it is clearly different from everything in the shared archive, add it. Both agents now avoid it.
  6. Each agent keeps its best drawing and, next round, either tweaks it or tries a fresh combination.
  7. After the last round, show the best drawings as choices to the human designer.

7. Pseudocode

function MultiAgentDrawing(parentA, parentB, rounds, k):
    archive ← { };  best[agent] ← none for both agents
    for r = 1 to rounds:
        for each agent in {A-spiral, B-star}:
            repeat k times:
                if best[agent] exists and random() < 0.6:
                    candidate ← combine(best[agent].operator, mutate(best[agent].params))
                else:
                    op ← random choice from agent's favourite operators
                    candidate ← combine(op, random params)          # new action
                drawing ← run_turtle(candidate)                         # new state
                score ← fitness(drawing)
                if overlap(drawing, every archived drawing) < 0.6: archive.add(drawing)
                if score > best[agent].score: best[agent] ← candidate
    return best drawings + archive

8. What could the fitness function be?

Fitness = 0.4 × Novelty + 0.4 × Aesthetics + 0.2 × Inheritance

  • Novelty = 1 − the largest overlap (IoU of the pixel grids) with either parent. A drawing that looks like a plain spiral or a plain star scores low.
  • Aesthetics borrows from Alexander's living geometry. It combines:
    • local symmetry (does the drawing match itself after a 3-, 4-, 5-, 6- or 8-fold rotation?);
    • balanced coverage (about 30% of the canvas inked);
    • levels of scale (a healthy mix of short and long strokes).
  • Inheritance = 1 − |2·shareA − 1|. It is 1.0 when both parents contribute equally, so the child is a real combination and not a copy of one parent.

10. How do both agents create new states together?

  • Different styles. A-spiral prefers blend; B-star prefers interleave. Their proposals come from different corners of the search space, which keeps diversity high. This is co-operative creativity, not two copies of one agent.
  • Shared archive. Once one agent adds a drawing, the other gets no credit for repeating it. The pair is pushed toward fresh states.
  • Learning from each other. Both agents ended up favouring "compose", because the archive and scores showed it worked.
  • The final archive is a set of choices, not one answer. A human artist can pick the one they like.

12. Summary

A search space is everything reachable through the available actions. Combining one action from each parent (compose, blend, nest, interleave) adds new actions. That grew the space 28.7 times and produced drawings neither parent could make. A fitness of novelty + aesthetics + balanced inheritance, plus a shared archive, guided two agents from fitness 0.62–0.70 to 0.75–0.79.
