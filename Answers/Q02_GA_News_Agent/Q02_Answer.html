Q2. Goal-Based News Agent with a Genetic Algorithm

Question. For a "news reporting" product, design a goal-based agent that uses a genetic algorithm (GA) in its agent function. S is the original set of news and G is the target news with the expected reader impact. Every square in Diagram 2 has a fitness and comes from legal moves with genetic operators. Give the detailed design: an initial population of at least four news items, four genetic operators, a fitness function, pseudocode, the working algorithm and a discussion of exit criteria. No more than two black squares may be visited in a row.

1. The idea in plain words

Think of Diagram 2 as a map of every version of one news story. S is the story as first written. G is the version that gives the impact we want on readers. Each square is a version, and a move to the next square is one edit: swap the headline, add a fact, change the tone, cut a sensational line. The GA does not walk one path. It grows a whole population of edit sequences, keeps the ones that get closest to G, mixes them and mutates them. After some generations, one sequence reaches G safely.

2. Assumptions

  • The map has 7 × 12 squares. Grey squares are acceptable versions (quality 0.7). Black squares are risky versions: sensational, unverified or biased (quality 0.2).
  • C and D are editorial checkpoints (fact-check desk and legal desk). Passing through them earns a small bonus.
  • Rule from the question: no more than two black squares in a row. A third black square in a row is a violation.
  • An edit that would leave the map is skipped (that operator does nothing).

The four genetic operators

MoveOperatorWhat it does to the story

Real example from the run, on "SHOCK: city bridge collapses, thousands trapped!": the delete operator gives "City bridge collapses, thousands trapped", and the tone mutation gives "Bridge section collapses in city; rescue under way".

Fitness function

F = 0.45·closeness + 0.30·reached + 0.15·avg quality + 0.05·checkpoints − 0.12·violations − 0.002·length

  • closeness = 1 − (distance from the final square to G) / 17. This is the gap to the target impact.
  • reached = 1 if the path ends on G. avg quality = mean quality of the visited squares.
  • checkpoints = how many of C and D the path passes (0–2).
  • violations = number of squares that make a run of three or more black squares. This is the penalty for the rule.

4. Working algorithm (step by step)

  1. Create 60 random operator sequences. Each starts at S.
  2. Run each sequence on the map and compute its fitness.
  3. Check the exit criteria (section 6). If met, return the best path.
  4. Pick parents by tournament (best of 3 random sequences).
  5. Crossover: join the first part of one parent with the second part of the other.
  6. Mutate: each gene has a 4% chance of becoming a random operator.
  7. Copy the 2 best sequences unchanged (elitism), fill the rest with children and go to step 2.

5. Pseudocode

function NewsAgent(S, G):                                  # goal-based agent function
    population ← 60 random operator sequences (length 30)
    for generation = 0 .. MAX_GEN:
        for each seq in population:
            path ← apply operators from S, skip moves that leave the map
            fitness(seq) ← closeness + reached + quality + checkpoints
                            − penalty(black squares in a row > 2) − length cost
        best ← sequence with the highest fitness
        if best reaches G and has no violations and no gain for 15 generations: return best
        new ← the 2 best sequences
        while new is not full:
            p1, p2 ← tournament_selection(population)
            child ← one_point_crossover(p1, p2)
            mutate each gene with probability 0.04
            new.add(child)
        population ← new
    return best

6. Exit criteria

A GA never knows it is "done", so we need clear stopping rules. The agent stops when any of these is true:

RuleWhy
Goal met: best path ends on G with zero rule violationsThe story reaches the target impact safely. This is the main rule.
Plateau: no improvement for 15 generationsMore search is wasting time. Combined with the goal rule, it also lets the path get shorter first.
Generation limit (150) or time budgetThe news deadline is fixed. The agent must publish something.
Editor approval (manual inspection)A human can accept a good enough version at any time.

The black-square rule is not an exit rule. It is a feasibility check: a path with violations can never be the final answer.

9. Summary

The agent is goal-based, and its planning step is a GA. Each square is a news version, each move is one genetic operator, and fitness combines closeness to the target impact, quality, checkpoints and the black-square rule. The GA exited at generation 54 with a legal 21-move path from S to G. Clear exit rules (goal met, plateau, limit, editor) keep it from running forever.
