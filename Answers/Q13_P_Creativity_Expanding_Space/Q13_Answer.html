Q13. Psychological Creativity as a Special Function of Historical Creativity

Question. Model psychological (P) creativity as a special function of historical (H) creativity. Begin with a constrained search space so most actions can be creative. Slowly expand the space and eliminate states. When no state is left, combine the n top-performing states into new states. Continue until no new state falls beyond the final expanded space, then deliver the final states ranked (Diagram 5).

1. The idea in plain words

H-creativity means the idea is new to the whole world. P-creativity means it is new to me, even if others had it before. The only difference is what memory we compare against. H compares with everything humans have ever produced. P compares only with what this agent has seen. So P is H with a smaller memory. Because the agent knows less than history, anything that is new to history is also new to the agent. Every H-creative idea is P-creative, but not the other way round.

The algorithm then works like a curious person exploring: start with a small, safe area near one idea (so almost everything feels new), widen it slowly, throw out weak ideas, and when the area is used up, mix the best ideas to make new ones and move on.

3. Assumptions

  • An idea is a point in a 2-D conceptual space (0 to 11.5 on each axis). Its value (usefulness, 0 to 100) comes from a landscape with one broad slope and three hills.
  • The agent starts at idea j = (2, 2), which has value 12.
  • A pool of 260 candidate ideas is spread over the space. The history archive has 30 ideas and the agent remembers only 7 of them.
  • Novelty threshold τ = 1.0. Ideas with value below 14 are weak and are eliminated. n = 4 top states are combined.
  • The search circle starts at radius 1, grows by 1 per round, and is capped at 3 per stage.

4. Step-by-step approach

  1. Constrain: start with a small circle (r = 1) around j. Few states, so most actions are new to the agent.
  2. Examine and eliminate: visit every unvisited state in the circle. Remove visited states from the space and eliminate those with low value. Keep the good ones.
  3. Expand slowly: grow r by 1 and repeat, until the cap is reached and no unvisited state is left.
  4. Combine: take the n best kept states and blend each pair into a new state (a point on the line between them, a little beyond if lucky).
  5. Move the centre to the best new state (j → n1 → n2 …) and start a new small circle there.
  6. Stop when none of the new states lies beyond the space already covered. Then rank all states by value.

5. Pseudocode

function CreativeSearch(pool, j, tau_v, n):
    centre ← j;  VISITED ← { };  KEPT ← [ ];  COVERED ← [ ]
    repeat (stage = 1, 2, ...):
        r ← r0                                         # small, constrained circle
        loop:
            SPACE ← { s in pool : s not in VISITED, dist(s, centre) ≤ r }
            KEPT += { s in SPACE : value(s) ≥ tau_v }    # weak states are eliminated
            VISITED += SPACE                                # visited states are eliminated
            if r ≥ r_cap: break                         # space is empty
            r ← r + dr                                 # slow expansion
        COVERED.add(circle(centre, r_cap))
        TOP ← n best of KEPT by value
        NEW ← { blend(a, b) : a, b in TOP }            # combine top performers
        pool += NEW
        if no state of NEW is outside COVERED: break
        centre ← best of NEW                           # j -> n -> i
    return all states ranked by value

The start idea j had value 12, and the best final idea has value 85.3. Across all 117 states the search kept or created, 97 are P-creative and 53 are H-creative, and every H-creative one is also P-creative. Figure 4 shows why: no point sits above the diagonal.

Honest limit. The search ended on the hill at (3, 8) with value 85. The tallest hill (around (9, 9), value about 100) was never reached, because every new state was built from states near the old ones. Restarting from a second idea, or letting the combination step extrapolate further, would reach it. This is the same local-maximum problem as hill climbing.

8. Why start constrained?

A small first circle keeps the agent's decisions simple and cheap, and it makes most moves new to this agent (P-creative) because it has seen so little. Constraints also focus creativity, as the course notes say. Widening the circle slowly, and only combining when the space is empty, is how the agent moves from exploring to combining and toward H-creativity. It also corresponds to Boden's forms: exploring inside the space first, then combinational creativity, and a shifting centre that gradually transforms the space.

10. Summary

P-creativity is H-creativity measured against a smaller memory: noveltyP ≥ noveltyH, so every H-creative idea is P-creative. The algorithm starts in a small circle, expands it slowly, eliminates visited and weak states, and when the space is empty combines the top n states, moving the centre j → n → i until no new state lies outside the covered space. In the real run, the best idea improved from value 12 to 85.3, with 53 H-creative states among the 117 produced.
